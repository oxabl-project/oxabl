## 2. ABL `AVAILABLE` keyword not callable (MINOR)

`Kind::Available` exists but is not in the callable list. `DISPLAY x WHEN AVAILABLE(Customer).` would fail. Fix: add `Kind::Available` to `callable.rs`.

## 3. Missing ABL keywords from lexer (MEDIUM)

The following keywords are not in the lexer's keyword list — they're handled as `Kind::Identifier` with text matching in the parser:

**Currently worked around with `is_identifier_text()`:**
- `var`, `function`, `temp-table`, `buffer`, `catch`, `finally`, `throw`, `primary`

**Needed for future OO-ABL support (not yet implemented):**
- `CLASS`, `METHOD`, `PROPERTY`, `CONSTRUCTOR`, `DESTRUCTOR`, `INTERFACE`, `INHERITS`, `IMPLEMENTS`, `PUBLIC`, `PRIVATE`, `PROTECTED`, `ABSTRACT`, `OVERRIDE`, `STATIC`, `FINAL`

**Recommended fix:** Add to `resources/keyword_overrides.toml` and run `cargo run -p oxabl_codegen`.
